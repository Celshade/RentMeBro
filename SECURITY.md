# Security Policy

## Supported Versions

RentMeBro is early-stage (alpha) and not deployed as a live service.
There is one actively maintained line of development, tracked on the
`develop` branch — no older versions receive security fixes.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security
vulnerabilities.

Instead, use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/Celshade/RentMeBro/security/advisories/new)
(also reachable via the repo's **Security** tab → **Report a
vulnerability**).

Include what's affected, how to reproduce it, and its potential
impact. This is a solo-maintained project, so response times aren't
guaranteed, but reports are reviewed and taken seriously.
